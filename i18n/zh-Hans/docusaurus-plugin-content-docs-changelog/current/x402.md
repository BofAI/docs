# x402支付协议

x402 协议、SDK 与 [CLI](/zh-Hans/x402/cli/) 的版本发布记录。

### 文档对照源码全面校核

<div className="changelog-tags"><span className="changelog-tag">文档</span><span className="changelog-tag">修复</span></div>

- **API 目录示例按真实 provider 重建**——`catalog.json` 与 `pay.md` 示例现已与 `providers/sunpump-token-launch/` 一致：三条链、四条路由，含 TRON `exact_gasfree` 与 Base 的 `eip3009` 路由。此前的示例缺少 `assetTransferMethod`，直接照抄会通不过 schema 校验。提交前检查清单也补上了该字段何时必填、何时必须省略，以及同一网络可以有多条路由。
- **结算记录的去重说法**——facilitator 页此前称成功的结算会按授权身份去重。实际并非如此：`/settle` 每次尝试都插入一行，表上没有唯一约束，也不存在 upsert 或预检。每个授权身份至多只有一条成功记录，仅仅是因为链上的重放保护只允许结算一次。同时补充了 `/payments` 记录流的 `limit`（默认 `50`、上限 `200`）与 `offset` 默认值，以及 `not_found` / `invalid_identity_query` / `missing_identity_or_auth` 三个错误码。
- **字段修正**——`subTitle` 并非合法的 provider 字段（schema 拒绝未知键，只有 `subtitle`），已删除，连同引用它的 `sub_title` 推导说明。Base Sepolia 标注为仅 schema 层面可用：构建脚本没有它的展示元数据。
- **载荷描述准确化**——转账授权在 EIP-3009 路径下位于 `payload.authorization`，Permit2 路径下位于 `payload.permit2Authorization`。若 permit2 资产同时实现 EIP-2612，`extra` 会带上 `name`/`version`——这是客户端改签无 gas permit、而非广播 `approve` 的信号。
- **能力范围收窄**——余额感知的付款选择与最低价代币策略仅 TRON 可用；`HTTPFacilitatorClient` 的限流重试只作用于 `getSupported()`，`verify()` 与 `settle()` 会直接抛出 429。协议网络列表补上了 TRON Shasta。
- **支付记录查询**——修正了匿名访问的描述：不带 API Key 时，`tx_hash` 与 `network` + `nonce` 查询都不施加卖家过滤，任何持有准确标识符的人都能查到对应记录。虽然不存在免认证的列表接口，但这两个查询同样没有限流（官方服务按每个 IP 每分钟 1 次的匿名限流只覆盖 `/settle`），而结算 tx hash 又是链上公开数据，因此结算元数据事实上是公开的，而非按卖家隔离。文档已明确标注这是当前实现行为，不代表推荐的访问控制策略。
- **Facilitator**——删除了残留的手续费表述。EVM 的 ERC-20 授权 gas 代付按真实条件重新说明：SDK 不会自动注册，自建 facilitator 需显式启用，官方 facilitator 已为 BSC 与 Base 注册，且资源服务端必须在路由上声明该扩展才会生效。
- **CLI 参考**——`/health` 与 `/.well-known/x402` 不限请求方法，后者还会返回 `rawAmount` 与 `pay_url`；补充了 `--providers-dir`、`--query` 别名，`catalog build` 位置参数的默认值，以及 `export-gateway` 的默认输出目录。

### x402 SDK v1.2.0 —— TRON 授权资源赞助

<div className="changelog-tags"><span className="changelog-tag">新版本</span><span className="changelog-tag">SDK</span><span className="changelog-tag">TRON</span></div>

- **新增 `trc20ApprovalResourceSponsoring` 扩展**（协议 schema 版本 `1`），适用于 TRON 的 `exact`、`upto` 以及 `batch-settlement` 的 Permit2 存入/补充路径。付款方只签名 `approve(Permit2, MaxUint256)` 而**不广播**；facilitator 严格解码已签名交易、将其与本次付款绑定校验，临时委托付款方所缺的 Stake 2.0 能量（必要时还有带宽），原封不动地广播该交易，并通过可恢复的状态机回收委托资源。因此付款方首笔授权无需 TRX。未新增任何接口——流程仍为 `402` → `PAYMENT-SIGNATURE` → `/verify` → `/settle`。
- **Facilitator 赞助 runtime**——包含 Stake 2.0 资源量估算、有界的赞助策略、持久化操作协调器契约、崩溃恢复与资源回收。进程内的 `InMemoryTrc20SponsoringCoordinator` 仅用于测试与开发；生产环境需要持久化协调器并定时对账。
- **TRON 客户端授权策略**——代币现在会解析出逐代币的授权更新策略，赞助路径与自付 gas 路径共用：`zero-first`（已知 Permit2 资产的默认值，遇到非零但不足的额度会报 `approval_reset_required`）、需显式启用的 `direct-overwrite`，以及针对未知资产的 `unsupported`（报 `approval_asset_unsupported`）。SDK 不会自动插入 `approve(0)`。
- **版本组合**——`@bankofai/x402-extensions` 与 `@bankofai/x402-tron` 升至 `1.2.0`；`@bankofai/x402-express`、`-fastify`、`-hono`、`-next` 升至 `1.1.1`；`@bankofai/x402-core`、`-evm`、`-fetch`、`-axios`、`-mcp` 因 API 与依赖未变而保持 `1.1.0`。Node.js 22+ 要求不变。
- 官方 facilitator 目前**未**启用该扩展；TRON 授权赞助需要自建 facilitator，并准备资源持有钱包。

### x402 SDK v1.1.0 —— 付款流程与钱包兼容

<div className="changelog-tags"><span className="changelog-tag">新版本</span><span className="changelog-tag">SDK</span></div>

- **付款流程改为显式声明**——scheme/network server 按资产转账方式声明支持的流程。`upfront` 与 `escrow` 通过 `extra.paymentFlow` 传递；`authorization` 仍是默认流程，不写入 `extra`。未声明流程的 v1.0 服务端继续沿用 authorization。
- **客户端消费管控默认开启**——client 只支付默认资产注册表中认识的资产，且每笔上限为 `DEFAULT_MAX_AMOUNT_PER_PAYMENT`（约合 `$1`）。可用 `spendControls.maxAmountPerPayment` 提高上限、用 `spendControls.allowedAssets` 放行自定义代币，或用 `spendControls: false` 关闭该防护。
- **付款选择策略与生命周期钩子**——新增 `PaymentPolicy`，以及 `onBeforePaymentCreation` / `onAfterPaymentCreation` / `onPaymentCreationFailure` / `onPaymentResponse`。
- **EVM 钱包兼容性**——支持已部署的智能账户、ERC-7702 委托，以及白名单内的 ERC-6492 反事实钱包；ERC-6492 需要在 facilitator 上显式配置 `eip6492AllowedFactories`。
- **`HTTPFacilitatorClient`** 新增带类型的超时错误、限流重试、更严格的响应校验，默认超时 90 秒。
- **11 个 `@bankofai/x402-*` 包需整体升级**——内部依赖解析为 `~1.1.0`。SDK 要求 **Node.js 22+**。自定义 money parser 现在接收十进制字符串。

### x402 CLI v1.0.2 —— Base USDC 与 Agent Wallet

<div className="changelog-tags"><span className="changelog-tag">新版本</span><span className="changelog-tag">CLI</span><span className="changelog-tag">Base</span></div>

- **支持 Base**——`eip155:8453`（主网）与 `eip155:84532`（Sepolia），均支持 USDC，并提供 `base-mainnet` / `base-sepolia` 别名。Base 走标准 `exact` 方案，但使用 **EIP-3009** 授权而非 Permit2。生产环境请通过 `--rpc-url` 或 `EVM_RPC_URL_8453` / `EVM_RPC_URL_84532` 自备 RPC。
- **Agent Wallet 成为默认付款方**——`pay` 会解析你当前激活的 [Agent Wallet](/zh-Hans/Agent-Wallet/Intro/) 并交由它签名，私钥不再需要放进环境变量。如果配置了钱包但没有激活项，CLI 会**在签名前停下**而不是替你选一个。可用 `--wallet-id` / `AGENT_WALLET_ID` 显式指定，或用 `AGENT_WALLET_DIR` 指向其他目录。私钥现在只作为开发/CI 的覆盖手段。
- **付费请求不再跟随重定向**，确保 `PAYMENT-SIGNATURE` 不会被转发到其他源。
- **EVM 余额预检**——签名前校验付款方代币余额，并返回解析出的钱包 ID、地址与原始余额。
- 新增：`pay --asset` / `--decimals`、`serve --valid-for-seconds`（默认 `300`），以及 `roundtrip --json` 输出单个文档、内含独立的 `serve` 与 `pay` 结果。
- 新增钱包类错误码：`WALLET_PASSWORD_REQUIRED`、`WALLET_DECRYPTION_FAILED`、`WALLET_CONFIG_CORRUPT`、`WALLET_NETWORK_ERROR`。

### 官方 Facilitator —— 支持 Base 结算

<div className="changelog-tags"><span className="changelog-tag">更新</span><span className="changelog-tag">Facilitator</span><span className="changelog-tag">Base</span></div>

- 官方 facilitator 现已结算 **Base USDC**：在 TRON 主网/Nile、BSC 主网/测试网之外，新增启用 `eip155:8453`（主网）与 `eip155:84532`（Sepolia）。
- 所有已启用网络均注册 `exact`、`upto` 与 `batch-settlement`；TRON 在服务持有 GasFree 中继凭证的网络上额外注册 `exact_gasfree`。以 `/supported` 返回为准。仓库自带的示例 facilitator（`facilitator/basic`）在 EVM 侧仍只注册 `eip155:97` 与 `eip155:56`（其 `TRON_NETWORKS` 已含 Nile/Shasta/主网），自托管的 Base 卖家需自行把 Base 的网络 ID 加进 `EVM_NETWORKS`。

### x402 CLI v1.0.0

<div className="changelog-tags"><span className="changelog-tag">新版本</span><span className="changelog-tag">CLI</span></div>

`@bankofai/x402-cli` 首个正式版发布——用于 x402 支付的 TypeScript 命令行客户端。

- **`pay`** —— 支付任意受 x402 保护的 URL：探测接口、读取 `402` 支付要求、签名并重试
- **`serve`** —— 启动本地 x402 付费端点，通过 Facilitator 校验并结算
- **`roundtrip`** —— 启动临时服务、支付、退出：最快的端到端冒烟测试
- **`gateway`** / **`catalog`** —— 校验与生成 provider 文件；搜索、缓存、导出服务目录
- 基于已发布的 `@bankofai/x402-core` / `x402-evm` / `x402-tron` SDK 1.0 包构建；`scheme=exact` 配合 Permit2
- 支持网络：TRON（`tron:mainnet` / `tron:nile` / `tron:shasta`）与 BSC（`eip155:56` / `eip155:97`）

👉 立即上手：[x402 CLI 快速开始](/zh-Hans/x402/cli/quickstart/)
