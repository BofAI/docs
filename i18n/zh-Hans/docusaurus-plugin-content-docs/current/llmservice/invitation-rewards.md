# 邀请返利规则

B.AI 邀请返利支持你邀请好友注册，并在符合条件的被邀请好友完成充值或订阅后获得 Coin。本页说明邀请注册奖励、邀请返利、Coin 到账、兑换及调整规则。

## 1. 邀请注册奖励

好友通过你的专属链接或邀请码完成注册后，可领取 `300,000 Credits` 邀请注册专属礼包。

* 每位用户只能绑定一位邀请人。
* 用户不能邀请自己。
* `300,000 Credits` 邀请注册专属礼包属于免费赠送 Credits，自发放日起 30 天内有效；过期后未使用部分将自动失效。

## 2. 邀请返利

邀请关系建立后有效期为两年。有效期内，好友完成符合条件的充值或订阅时，你可获得 Coin 返利。

返利按照被邀请好友实际支付的有效金额计算；赠送金额、优惠金额、退款金额及异常订单不计入返利。

当前基础返利比例为 `1%`。你可以填写平台提供的邀请大使申请表，审核通过后可能获得更高返利比例。

:::info 当前比例与资格

以推广返利中心页面向你的账户展示的返利比例为准。平台可按照本页所述规则调整返利比例和适用资格。

:::

## 3. Coin 到账时间

Coin 到账前会显示为「待发放」，具体预计到账时间以账单页面展示为准。

| 符合条件的支付方式 | Coin 预计到账时间 |
| :--- | :--- |
| Crypto 充值 | 付款成功后的第 1 天预计到账 |
| 法币充值 | 付款成功后的第 30 天预计到账 |
| 订阅 | 付款成功后的第 30 天预计到账 |

实际到账时间以账单页面展示的预计到账时间为准。

## 4. Coin 有效期与使用方式

已到账的 Coin 永久有效。目前 Coin 可兑换为 Credits，未来可能开放更多使用方式，具体以届时规则为准。

## 5. Coin 兑换 Credits

1. 前往「推广返利中心」。
2. 点击「兑换」。
3. 输入想兑换的整数 Coin 数量。

当前兑换比例为 `1 Coin = 1,000,000 Credits`。兑换比例由平台设定；如有调整，以推广返利中心兑换页面实时展示为准。

兑换时请注意：

* 每次最少兑换 `1 Coin`。
* 支持部分兑换或全部兑换，但兑换数量必须为整数。
* 只能使用已到账的 Coin；待发放或待扣回的 Coin 不可兑换。
* 兑换数量不能超过当前可用 Coin。
* 兑换成功后，Coin 立即扣减，Credits 立即到账。
* 兑换获得的 Credits 自发放日起 30 天内有效。
* 兑换成功后不可撤销。

## 6. 退款与异常处理

如被邀请人存在异常注册、违规使用、退款、拒付、争议或账号封禁等情况，平台可取消待发放的 Coin，或扣回已经发放的 Coin。

如当前可用 Coin 不足以扣回，未扣回部分将显示为「待扣回」，并从后续获得的 Coin 中抵扣。

:::caution 规则调整

B.AI 保留根据活动运行情况调整返利比例、兑换比例、到账周期及相关规则的权利。调整后的规则以推广返利中心和账单页面的最新说明为准。

:::
