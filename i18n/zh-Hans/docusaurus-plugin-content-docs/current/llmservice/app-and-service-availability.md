# B.AI Android App 与服务可用性

B.AI Android App 集成了 B.AI 的主要功能与页面，并提供 **B.AI 服务可用性**功能。中国大陆及其他网络环境的用户如无法直接访问 B.AI Web 或 API，可通过该功能查看当前网络环境下可用的 Web 访问地址和 API Base URL。

## 下载 App

B.AI Android App 支持 Android 8.0 及以上版本，可通过以下官方方式下载安装：

- **Google Play：** [通过 Google Play 安装 B.AI](https://play.google.com/store/apps/details?id=com.bai.chat)。
- **官方 APK：** 访问 [B.AI 官网](https://b.ai/)，扫描页面右上角的 Android 下载二维码。

为方便用户使用，官方 APK 下载二维码也展示如下：

![B.AI Android App 官方 APK 下载二维码](/img/bai-android-download-qr.png)

请仅通过上述 Google Play 页面或 B.AI 官网提供的二维码安装 App。

## 查看可用服务地址

打开 B.AI Android App，进入 **B.AI 服务可用性**，即可查看：

- **Web 访问地址：** 打开可用地址，使用 B.AI Web 服务。
- **API Base URL：** 将可用地址复制到 API 客户端或集成工具的 Base URL 配置项中。

配置 API 客户端时，请完整复制 App 中展示的 API Base URL，不要自行增加或删除路径。鉴权方式、请求协议及调用示例请参阅 [API 参考](./api/API.md)。

具体服务地址由 App 统一维护，本文档不重复列出。需要确认当前网络环境下的可用地址时，请重新打开 **B.AI 服务可用性**查看。
