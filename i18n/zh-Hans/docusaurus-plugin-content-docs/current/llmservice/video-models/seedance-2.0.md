# Seedance 2.0

## 概述

Seedance 2.0 是字节跳动 Seed 于 2026 年 2 月 12 日发布的视频生成模型，采用统一的多模态音视频联合生成架构。它是 Seedance 2.0 系列中偏重生成质量的版本，支持参考生成、编辑和延长，单次最长生成 15 秒视频，输出分辨率最高为 4K。

:::info 平台开放范围
以下规格描述模型提供方的能力。B.AI 实际开放的功能、分辨率、参考素材路径及限制以平台支持情况为准。调用时应使用平台展示的模型 ID，不应将展示名称直接视为 API 模型 ID。
:::

## 核心特性

- **高分辨率生成：** 支持 1080p 和 10-bit 色彩的 4K 输出，为高分辨率素材制作提供选择。
- **多模态参考控制：** 可结合最多 9 张图片、3 段视频和 3 段音频，参考主体、构图、动作、镜头及声音。
- **音画联合生成：** 可在同一任务中生成视频及对白、音乐或音效。
- **视频编辑与延长：** 支持根据提示词修改已有视频及向前、向后延长，多段参考视频可用于指导转场。
- **首帧与首尾帧控制：** 支持图生视频和首尾帧生成，适合图片动画化或连接指定画面。

## 适用场景

- 高分辨率广告与品牌视频
- 产品展示与社交媒体短视频
- 分镜与叙事原型
- 已有视频的修改、衔接与延长

## 生成规格

| 项目 | 说明 |
| :--- | :--- |
| **输入模式** | 文本、图片、视频和音频；音频参考需结合图片或视频 |
| **生成方式** | 文生视频、图生视频、首尾帧生成、参考生成、视频编辑和延长 |
| **参考素材上限** | 9 张图片、3 段视频、3 段音频；视频与音频各自的累计时长不超过 15 秒 |
| **生成时长** | 4-15 秒或自动 |
| **输出分辨率** | 480p / 720p / 1080p（8-bit）；4K（10-bit） |
| **画面比例** | 16:9、4:3、1:1、3:4、9:16、21:9 或自适应 |
| **输出帧率** | 24 FPS |
| **输出格式** | MP4 |
| **Draft 模式** | 不支持 |
| **任务交付** | 异步生成；不支持离线推理 |

### 计费说明

- 不含视频输入仍可包含图片或音频参考。视频 Token 不等于文字 Token，价格也不是每秒或每条视频的价格。
- 参考视频与生成输出一起参与计费用量。含视频输入的任务存在最低计费量，取决于分辨率、画面比例和时长。
- 4K 的 Token 单价较低，不代表生成相同时长的视频总费用更低，需要结合实际计费 Token 用量比较。
- 模型提供方仅对成功生成的视频收费，生成失败的任务不计费。B.AI 的任务状态、计费用量及最终结算以平台页面展示和账单记录为准。

**Credits 结算：** B.AI 按照 `1 USD = 1,000,000 Credits` 换算，并从账户余额中扣除 Credits。

## 使用与限制

以下限制与结果保留规则描述模型提供方的服务，B.AI 实际开放范围和任务处理以平台支持情况为准。

- 单次生成最长 15 秒。参考素材不能保证主体身份、动作和帧连续性完全一致，使用前应检查生成结果。
- 单段参考视频和音频均为 2-15 秒，并受各自累计 15 秒的限制。图片单文件小于 30 MB、视频不超过 200 MB、音频不超过 15 MB，请求体不超过 64 MB。
- 真人面部参考素材直接上传受限制，需要使用提供方支持的可信模型输出、预设数字角色或授权真人素材等资产路径。
- 首帧和首尾帧工作流中，输入与输出尺寸不一致可能导致画面拉伸或压缩。应匹配目标输出尺寸，或使用自适应画面比例。
- 4K 输出使用 H.265 / HEVC 编码，需要兼容的播放与编辑环境。提供方资料中的 4K 限制为每分钟创建 15 个任务、最多 1 个并发任务，企业与个人用户相同。
- 提供方保留任务记录 7 天；结果视频链接 24 小时后过期，最多允许下载 100 次，应及时保存生成文件。

### 异步生成流程

视频生成以任务形式执行：提交生成请求、查询任务状态，完成后获取结果，不是文本对话的流式回复。请使用 B.AI 支持的视频生成接口，不应在未确认兼容性的情况下直接使用聊天端点或提供方端点。

B.AI 的任务创建、状态查询、视频下载及计费说明见[视频生成 API](../api/videos.md)。
