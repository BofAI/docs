# 视频生成模型定价

Seedance 模型可根据文本及支持的图片、视频、音频参考素材生成视频，包括音画同步的视频内容。视频生成价格独立于文本输出模型和图像生成模型价格表展示。

## 标准价格

**价格单位：`USD / 1M Video Tokens`（美元／100 万视频 Token）。** 以下不是每秒或每条视频的价格，实际费用取决于计费视频 Token 用量。

| 模型 | 输出分辨率 | 不含视频输入<br/>（USD / 1M Video Tokens） | 含视频输入<br/>（USD / 1M Video Tokens） |
| :--- | :--- | ---: | ---: |
| [Seedance 2.0 Mini](./seedance-2.0-mini.md) | 480p / 720p | `$3.50` | `$2.10` |
| [Seedance 2.0 Fast](./seedance-2.0-fast.md) | 480p / 720p | `$5.60` | `$3.30` |
| [Seedance 2.0](./seedance-2.0.md) | 480p / 720p | `$7.00` | `$4.30` |
| [Seedance 2.0](./seedance-2.0.md) | 1080p | `$7.70` | `$4.70` |
| [Seedance 2.0](./seedance-2.0.md) | 4K | `$4.00` | `$2.40` |
| [Seedance 2.5](./seedance-2.5.md) | 480p / 720p | `$10.70` | `$6.40` |
| [Seedance 2.5](./seedance-2.5.md) | 1080p | `$11.70` | `$7.00` |

:::info 价格表阅读说明
- **不含视频输入**仍可包含图片或音频参考素材，不等于只有文字输入。
- **含视频输入**表示任务的输入场景，不是单独的视频输入 Token 价格；参考视频会与生成输出一起参与计费用量。
- 视频 Token 是视频计费单位，不是提示词的文字数量。分辨率、画面比例、时长及参考视频都可能影响用量，含视频输入的任务可能存在最低计费量。
- 4K 的 Token 单价较低，不代表生成相同时长的视频总费用更低，需结合实际计费 Token 用量比较。
:::

## Seedance 2.5 Draft 计费

Draft 预览和最终视频分别按适用的 480p、1080p 单价计费。最终生成计费使用原始请求中的输入视频，Draft 视频本身不作为额外输入累计计费。规格与限制详见 [Seedance 2.5](./seedance-2.5.md)。

## Credits 结算

B.AI 按照 `1 USD = 1,000,000 Credits` 换算，并从账户余额中扣除 Credits。

模型提供方的计费规则为仅对成功生成的视频收费，生成失败的任务不计费。B.AI 的任务状态、计费用量及最终结算以平台页面展示和账单记录为准。

:::info 价格说明
文档价格为 B.AI 平台模型标准参考价，仅供基础计费说明使用。B.AI 可能会通过充值赠送及账户权益等方式，为用户提供更低的实际使用成本。具体价格、赠送 Credits、账户权益及最终结算请以平台页面展示和账单记录为准。
