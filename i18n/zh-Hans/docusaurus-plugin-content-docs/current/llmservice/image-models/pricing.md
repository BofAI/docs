# 图像生成模型定价

不同图像生成模型可能采用不同计费方式。部分模型按照文本输入、图像输入和图像输出 Token 计费，部分模型按照实际生成图片数量计费。估算费用前，请先确认对应模型标注的计费单位。

按 Token 计费的价格以美元/100 万 Token 展示，按图片计费的价格以美元/张展示。B.AI 按照 `1 USD = 1,000,000 Credits` 换算并扣除 Credits。

## GPT-Image-2

**计费方式：** 按 Token 计费

GPT-Image-2 按文本输入、图像输入及图像输出 Token 的实际用量计费，不采用固定的单张图片价格。分辨率、质量、画面比例、参考图和生成数量都可能影响最终用量。

| 计费项目 | 标准价格（美元/100 万 Token） |
| :--- | ---: |
| 文本输入 | `5.00` |
| 图像输入 | `8.00` |
| 图像输出 | `30.00` |

[查看 GPT-Image-2 模型详情](./gpt-image-2.md)

## MiniMax-H3-Image / MiniMax-H3-Image-Highspeed

**计费方式：** 按 Token 计费

两个模型均按文本输入、参考图输入及图像输出 Token 的实际用量计费，不采用固定的单张图片价格。以下价格单位为美元/100 万 Token。

| 模型 | 文本输入 | 图像输入 | 图像输出 |
| :--- | ---: | ---: | ---: |
| MiniMax-H3-Image | `$2.30` | `$1.50` | `$3.80` |
| MiniMax-H3-Image-Highspeed | `$2.30` | `$3.00` | `$7.60` |

[查看 MiniMax-H3-Image 与 Highspeed 模型详情](./minimax-h3-image.md)
