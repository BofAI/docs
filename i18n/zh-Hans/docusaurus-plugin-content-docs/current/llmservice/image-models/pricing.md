# 图像生成模型定价

不同图像生成模型可能采用不同计费方式。部分模型按照文本输入、图像输入和图像输出 Token 计费，部分模型按照实际生成图片数量计费。估算费用前，请先确认对应模型标注的计费单位。

根据平台统一换算规则 `1 USD = 1,000,000 Credits`，对于按 Token 计费的模型，`USD X / 1M Tokens` 在数值上对应 `X Credits/Token`。

## GPT-Image-2

**计费方式：** 按 Token 计费

GPT-Image-2 按文本输入、缓存文本输入、图像输入、缓存图像输入及图像输出 Token 的实际用量计费，不采用固定的单张图片价格。分辨率、质量、画面比例、参考图和生成数量都可能影响最终用量。

| 计费项目 | 费率（Credits/Token） |
| :--- | ---: |
| 文本输入 | `5.00` |
| 缓存文本输入 | `1.25` |
| 图像输入 | `8.00` |
| 缓存图像输入 | `2.00` |
| 图像输出 | `30.00` |

## Grok Imagine Image 2.0

**计费方式：** 按实际生成图片数量计费

Grok Imagine Image 2.0 按实际生成图片数量计费，图像输出费率由分辨率和质量档位决定。

| 分辨率 | 质量 | 图像输出（Credits/张） |
| :--- | :--- | ---: |
| 1K | low | `40,000` |
| 2K | low | `60,000` |
| 1K | medium | `60,000` |
| 2K | medium | `80,000` |

参考图输入按 `10,000 Credits/张`计费。批量生成时，图像输出 Credits 按实际生成数量累加。
