# GPT-Image-2

## 概述

GPT-Image-2 是 OpenAI 的图像生成与编辑模型，支持通过文本提示词生成图片，也可结合参考图进行高保真图像编辑，适用于创意设计、营销素材和高质量视觉内容生产。

### 计费方式

GPT-Image-2 按文本输入、缓存文本输入、图像输入、缓存图像输入及图像输出 Token 的实际用量计费，并非采用固定的单张图片价格。分辨率、质量、画面比例、参考图和生成数量都可能影响最终 Token 用量。

## 核心特性

- **多种画面比例：** 支持 auto、16:9、3:2、1:1、2:3 和 9:16。
- **多档输出规格：** 支持 1K、2K 和 4K 分辨率，以及 Auto、low、medium、high 质量档位。
- **批量图片生成：** 单次可生成 1-8 张图片。
- **参考图编辑：** 最多支持 16 张参考图，可用于高保真图像编辑。
- **灵活控制成本：** 可通过分辨率、质量和生成数量适配不同生产需求。

## 适用场景

- 营销图片、海报、横幅、封面和社交媒体素材
- 产品概念、角色设计和视觉风格探索
- 需要精细画面表现的高分辨率创意内容
- 基于一张或多张参考图进行图像编辑
- 批量生成多个候选方案并进行比较

## 能力与限制

| 能力 | 说明 |
| :--- | :--- |
| **画面比例** | auto / 16:9 / 3:2 / 1:1 / 2:3 / 9:16 |
| **分辨率** | 1K / 2K / 4K |
| **质量档位** | Auto / low / medium / high |
| **单次生成数量** | 1-8 张 |
| **参考图数量** | 最多 16 张 |
| **参考图要求** | 单张不超过 10 MB；支持 jpg、jpeg 和 png；使用图片 URL |
| **透明背景** | B.AI 当前为该模型提供的接口暂不支持透明背景 |
