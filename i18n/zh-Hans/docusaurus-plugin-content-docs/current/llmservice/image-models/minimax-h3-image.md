# MiniMax-H3-Image / MiniMax-H3-Image-Highspeed

## 概述

[MiniMax-H3-Image](https://www.minimax.io/blog/minimax-h3-image) 是 MiniMax 于 2026 年 11 月 11 日发布的 H3 系列开放权重图像生成与编辑模型，结合细致的指令遵循、多参考图组合与原生 4K 生成能力，适用于创意制作和产品设计工作流。

## 模型版本

| 模型 | 说明 |
| :--- | :--- |
| **MiniMax-H3-Image** | 标准版，图像输入与图像输出 Token 价格更低。 |
| **MiniMax-H3-Image-Highspeed** | 高速版，生成速度更快，支持的输入类型、输出尺寸及参考图数量限制与标准版相同。 |

## 核心特性

- **图像生成与编辑：** 根据文本生成图像，或结合参考图与指令修改现有图像。
- **多参考图组合：** 最多结合 16 张参考图，控制主体、视觉风格、布局和产品摆放。
- **原生 4K 细节：** 可直接生成 4096 × 4096 的方形图像，呈现细致纹理与光照；自定义输出尺寸最高支持 2,000 万像素。
- **创意控制：** 遵循场景构图、物体位置、视角和视觉关系等细节要求。
- **提示词增强：** 将简短提示词扩展为更详细的描述；文生图时可选择关闭。

## 适用场景

- **游戏与概念设计：** 结合文字要求和视觉参考，探索环境、角色设定、幻想生物和电影感关键画面。
- **产品与电商视觉：** 将产品参考图融入生活场景，对比不同摆放方式或背景。
- **营销与包装概念：** 生成配色、图形和简短标签相互协调的宣传素材与包装方案。
- **创意迭代：** 对比视觉风格、调整视角和修改现有构图；高速版适合更重视生成效率的工作流。

## 能力与限制

以下[规格](https://platform.minimax.io/docs/guides/image-generation)适用于两个版本。

| 能力 | 说明 |
| :--- | :--- |
| **输入与输出** | 文生图使用文本输入；图像编辑使用文本与参考图输入；输出图像。 |
| **参考图** | 图像编辑支持 1–16 张参考图，每张不超过 64 MiB，单边尺寸为 128–8192 像素，长短边比例不超过 4:1。 |
| **输出尺寸** | 支持 1K、2K、4K 面积档位；自定义尺寸总像素数为 655,360–20,000,000。 |
| **画面比例** | 输出比例为 1:3 至 3:1；预设档位表示目标图像面积，而非固定边长。 |
| **单次生成数量** | 1–10 张，默认 1 张。 |
| **输出格式** | JPEG、PNG、WebP。 |
| **提示词长度** | 最多 32,000 个字符；关闭提示词增强时，约仅前 4,096 Token 生效。 |
| **提示词增强** | 文生图默认开启，图像编辑始终开启。 |

### 已知限制

- 不支持蒙版编辑、透明背景和预览图。
- 相比[标题、标签和简短注释](https://design.minimax.io/tools/h3-image)，长段落和密集文字的生成可靠性较低。
- 请求体总大小不超过 64 MiB；合并上传超过限制时，应使用图片 URL 或已上传文件引用。
- 生成图片的 URL 不保证保留时长，需保存返回的图片以便后续使用。
