# Grok Imagine Image 2.0

## 概述

Grok Imagine Image 2.0 是 SpaceXAI 的图像生成与编辑模型，支持通过文本提示词生成图片，也可结合多张参考图进行图像编辑，并提供多种画面比例、1K 和 2K 分辨率，以及 low 和 medium 质量档位。

### 计费方式

Grok Imagine Image 2.0 按实际生成的图片数量计费，输出价格由分辨率和质量档位决定；编辑时使用的每张参考图会单独计费。该模型不采用文本输出模型价格表中的输入、缓存写入、缓存读取和输出 Token 计费结构。

## 核心特性

- **多种画面比例：** 支持 auto、21:9、16:9、3:2、4:3、1:1、3:4、2:3 和 9:16。
- **多档输出规格：** 支持 1K 和 2K 分辨率，以及 low 和 medium 质量档位，默认使用 medium。
- **批量图片生成：** 支持同一提示词生成多张图片。
- **多图编辑：** 最多支持 3 张参考图。
- **按张计费：** 按实际生成数量、分辨率和质量档位计算费用。

## 适用场景

- 海报、横幅、封面、缩略图和社交媒体素材
- 角色、场景、产品外观和视觉风格探索
- 适配宽屏、移动端、人像和摄影等比例的视觉内容
- 基于参考图进行风格迁移、内容调整和组合创作
- 批量生成多个创意候选方案

## 能力与限制

| 能力 | 说明 |
| :--- | :--- |
| **画面比例** | auto / 21:9 / 16:9 / 3:2 / 4:3 / 1:1 / 3:4 / 2:3 / 9:16 |
| **分辨率** | 1K / 2K |
| **质量档位** | low / medium，默认 medium |
| **批量生成** | 支持同一提示词生成多张图片 |
| **参考图数量** | 最多 3 张 |
| **参考图要求** | 单张不超过 10 MB；支持 jpg、jpeg 和 png；使用图片 URL |
| **输出方式** | 默认返回临时 URL，也可请求 base64 |
