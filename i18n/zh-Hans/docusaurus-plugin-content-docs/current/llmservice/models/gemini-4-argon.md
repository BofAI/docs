# Gemini 4 Argon

## 概述

Gemini 4 Argon 是 Google DeepMind 于 2026 年 9 月 30 日公布、2026 年 10 月 13 日正式开放的推理模型，面向复杂软件工程、科学推理和企业知识工作，采用统一的百万 Token 上下文窗口，并支持长输出生成（Long Decode）。

## 核心特性

- **可调节推理：** 支持 `low`、`medium`（默认）和 `high` 思考级别，可按任务需要平衡推理深度、延迟和 Token 用量。
- **Agent 编程：** 面向复杂调试、代码迁移及需要反复分析和验证的软件工程流程。
- **企业分析：** 支持结合多份文档和证据开展复杂专业知识工作。
- **多模态理解：** 接受文本、图片、视频、音频和 PDF 输入，可分析图表和长视频，输出文本。
- **防御性网络安全：** 可在经过授权的 Agent 流程中识别、验证和修复软件漏洞。
- **扩展输出：** Long Decode 可在剩余统一上下文预算内生成超过 64K Token 的内容，具体取决于接口及执行方式。

## 适用场景

- **软件维护：** 需要多步调试、代码迁移、优化及验证的软件工程任务。
- **专业研究：** 结合多份文档证据的金融调查、法律研究或文稿起草。
- **视觉知识工作：** 结合文档推理进行图表解读和视频分析。
- **安全修复：** 在具备适当权限和安全措施的前提下开展漏洞发现及补丁验证。

## 能力与限制

| 能力 | 说明 |
| :--- | :--- |
| **推理能力** | 支持 `low`、`medium`、`high` 动态思考级别，默认使用 `medium`。 |
| **多模态能力** | 支持文本、图片、视频、音频和 PDF 输入，输出文本。 |
| **上下文窗口** | 输入、思考和输出共同使用 1,048,576 Token 的统一预算，并非分别享有独立的输入与输出额度。 |
| **最大输出** | 同步请求为 65,536 Token。提供方 Long Decode 可在接口支持的情况下使用最多 1,048,576 减去输入 Token 的剩余预算，其中包含思考 Token。 |
| **工具使用** | 提供方能力包括函数调用、结构化输出、代码执行、File Search、URL 上下文、Search 与 Maps grounding，以及 Computer Use（预览）。B.AI 实际支持情况取决于所用端点。 |
| **视频理解** | Agent 视频理解已正式开放，视频处理模式默认使用 `static`。 |
| **提示词缓存** | 仅支持隐式缓存，对至少 4,096 Token 的提示词默认启用；不支持显式缓存。 |
| **知识截止时间** | 2026 年 3 月，部分领域知识可能更早。 |

### 已知限制

- **输出预算：** 思考过程会占用生成预算。上限较小时可能出现截断或空回答；输入越长，可用于生成的剩余空间越少。
- **Long Decode：** 提供方 Interactions API 中超过 65,536 Token 的输出需要后台执行，并提高输出上限；不能假设所有 B.AI 端点均支持相同方式。模型也不能可靠保证精确的字数或 Token 长度。
- **不支持的功能：** 不支持显式缓存、原生图像或音频生成及 Live API。Computer Use 仍处于预览阶段。
- **采样参数：** `temperature`、`top_p` 和 `top_k` 会被忽略。
- **可靠性与延迟：** 仍可能出现幻觉、响应较慢或超时，复杂提示词可能需要数分钟。
- **评测条件：** 提供方评测可能使用最高思考级别和不同测试环境，评测成绩不代表实际生产效果保证。
