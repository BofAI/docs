# Gemini 4 Neon

## 概述

Gemini 4 Neon 是 Google DeepMind 于 2026 年 11 月 18 日发布的多模态推理模型。该模型基于 Gemini 4 Carbon 调整而来，在 Gemini 4 系列中定位于 Hydrogen 和 Carbon 之间，面向需要快速完成的复杂编程、分析和多步骤工作流。

## 核心特性

- **多文件编程**：结合测试完成跨文件实现、调试和验证。
- **工具辅助工作流**：将前一步结果用于后续步骤，并在任务过程中根据用户反馈调整处理方式。
- **多模态分析**：在同一请求中结合文档、图像、音频和录制视频进行分析。
- **可调节推理**：根据任务难度平衡响应时间和 Token 消耗。
- **Long Decode**：适用于所需生成容量超出单次同步响应限制的任务。

## 适用场景

- **软件维护**：跨模块追踪回归问题、实现修复，并通过现有测试验证。
- **技术文档审核**：比较规格、图示和录制资料，提取需求或识别不一致之处。
- **科学与定量分析**：探索数学问题，解释数据集或图表中的规律。
- **工作流自动化**：收集信息、通过工具验证，并返回可供下游系统使用的记录。

## 能力与限制

| 能力 | 说明 |
| :--- | :--- |
| **输入与输出** | 支持文本、图像、视频、音频和 PDF 输入，输出文本。 |
| **上下文窗口** | 输入、思考和输出共同使用 1,048,576 Token 的统一预算。 |
| **生成上限** | 默认同步响应的思考与输出合计最多 65,536 Token。Long Decode 可通过后台执行或续接使用剩余上下文预算。详见 [Long Decode 指南](https://aistudio.google.com/docs/long-decode)。 |
| **思考级别** | 支持 `low`、`medium`、`high`（默认）和 `xhigh`。 |
| **工具使用** | Google Gemini API 支持函数调用、代码执行、文件搜索、URL 上下文、搜索与地图 grounding，以及计算机操作。 |
| **结构化输出** | 支持受 Schema 约束的 JSON 响应。 |
| **视频理解** | 默认采用静态处理，并支持 Gemini API 中可选的 Agent 视频理解。 |
| **提示词缓存** | Gemini API 对符合条件、至少达到 4,096 Token 的提示词支持自动前缀缓存。 |

### 已知限制

- **推理成本与延迟**：`xhigh` 级别可能需要更长时间并消耗更多 Token；复杂提示词的处理可能耗时数分钟。
- **采样参数**：Gemini API 使用固定的采样设置，有效的自定义 `temperature`、`top_p` 和 `top_k` 值会被忽略。
