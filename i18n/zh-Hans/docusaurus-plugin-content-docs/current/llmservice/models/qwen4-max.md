## 核心特性

- **可配置推理：** 支持切换思考与非思考模式，并提供三档推理强度，适配需要深入分析的任务。
- **原生视觉理解：** 联合分析文本、图像与视频，适用于文档审阅、视觉推理和依赖视觉反馈的工作流。
- **百万 Token 上下文：** 可在单个上下文中处理大型文档集、代码仓库及长对话历史。
- **代码与专业工作：** 结合代码生成、资料检索、分析和工具调用，完成软件、报告等交付内容。
- **多步骤 Agent：** 支持函数调用与并行工具调用，完成规划、执行、检查和迭代流程。
- **上下文复用：** 显式缓存支持 5 分钟和 1 小时有效期，便于复用提示词、工具定义和参考资料。

## 适用场景

- **软件工程：** 利用代码仓库上下文和开发工具实现功能、排查问题并迭代测试。
- **专业分析：** 交叉核对资料，借助工具编制研究报告、财务工作簿或演示文稿。
- **视觉文档审阅：** 理解扫描件、图表、截图及视频，提取或总结关键信息。
- **研究工作流：** 结合文献调研、专业工具与实验反馈，完成多步骤科研和工程任务。

## 能力与限制

| 能力 | 说明 |
| :--- | :--- |
| **输入与输出** | 支持文本、图像与视频输入，输出文本。 |
| **推理** | 默认开启思考，默认推理强度为 high；支持 `low`、`high` 和 `xhigh`。 |
| **上下文窗口** | 1,000,000 Token。 |
| **最大输入** | 非思考模式为 991,808 Token；思考模式为 983,616 Token。 |
| **最大输出** | 非思考模式为 131,072 Token；思考模式下，思考与最终回答合计最多 262,144 Token。 |
| **思考预算** | 默认为 131,072 Token，包含在思考模式的合计输出上限内。 |
| **图像理解** | 单张图像最高约 1,600 万像素，通过 URL 最多传入 2,048 张图像，同时受上下文上限约束。 |
| **视频理解** | 单个视频最长 2 小时、最大 2 GB；单次请求最多 64 个视频，同时受上下文上限约束。 |
| **工具调用** | 支持函数调用与并行工具调用。 |
| **结构化输出** | 支持 JSON Object 和 JSON Schema 模式。 |
| **上下文缓存** | 支持隐式缓存，以及有效期为 5 分钟或 1 小时的显式缓存。 |

### 已知限制

- 输入包含图像或视频时，JSON Schema 请求会降级为 JSON Object 模式，不执行 Schema 约束。详见[结构化输出](https://platform.qianwenai.com/docs/developer-guides/text-generation/structured-output)。
- 模型提供方的内置代码解释器需要开启思考模式。

## 标准价格

以下 Token 价格均以美元计价，单位为每 100 万 Token，采用模型提供方新加坡国际站的标准原价。

| 计费项目 | 价格（USD / 1M Tokens） |
| :--- | ---: |
| 普通输入 | `$1.50` |
| 输出 | `$4.50` |
| 显式缓存写入（5 分钟） | `$1.875` |

| 缓存读取（隐式或显式） | `$0.075` |

**Credits 结算：** B.AI 按 `1 USD = 1,000,000 Credits` 换算费用，并从账户余额中扣除相应 Credits。

### 缓存计费说明

- 未配置缓存参数时，隐式缓存会自动识别可复用的输入前缀。创建缓存的 Token 按普通输入价格计费，不额外收取缓存写入费；缓存不保证每次命中。
- 显式缓存需要配置缓存参数，支持 5 分钟或 1 小时有效期。新增缓存写入 Token 分别按输入价的 1.25 倍或 2 倍计费，同一部分 Token 不再叠加普通输入费用。
- 隐式和显式缓存读取均为 `$0.075`／百万 Token。输出 Token（包括思考 Token）按输出价格计费。
- [定价与用量总表](../pricing-and-usage.md)同时展示两种显式缓存写入时长。对应参考价格及缓存机制可查阅官方[模型价格](https://www.alibabacloud.com/help/en/model-studio/model-pricing)和 [Qwen4 显式缓存规则](https://www.alibabacloud.com/help/en/model-studio/explicit-cache-qwen4)。
