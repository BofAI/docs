## 核心特性

- **视觉理解：** 结合文字指令识别图片中的文字、解读图表并分析截图。
- **长上下文分析：** 支持 1M Token 上下文窗口，最大输入 960,000 Tokens，可处理大量参考资料。
- **Agent 工作流：** 结合推理与函数调用，通过外部工具完成多步骤任务。
- **可调节思考：** 默认启用深度思考，也可在简单请求中关闭思考。
- **结构化响应：** 支持结构化输出，适用于信息提取、数据处理和应用工作流。

## 适用场景

- **软件开发：** 规划实现方案、分析代码，并结合截图进行界面开发与调试。
- **文档与图表分析：** 提取扫描文档中的信息、解读图表，并结合文字资料比较视觉证据。
- **研究与综合分析：** 基于长篇参考资料生成摘要、比较结果和推理分析。
- **办公 Agent：** 通过外部工具协调分析和文档编写，完成需要多个步骤的工作流。

## 能力与限制

| 能力 | 说明 |
| :--- | :--- |
| **输入与输出** | 支持文本和图像输入；输出文本，包括代码和结构化响应。 |
| **推理** | 默认启用深度思考，可关闭；支持在工具交互之间保留推理内容。 |
| **上下文窗口** | 1M Tokens。 |
| **最大输入** | 960,000 Tokens。 |
| **最大输出** | 64,000 Tokens。 |
| **工具调用** | 支持函数调用，通过外部工具完成多步骤工作流。 |
| **结构化输出** | 支持用于信息提取和下游处理的结构化响应。 |
| **图像输入** | 支持 PNG、JPEG、WEBP 和静态 GIF；单张图片最大 10 MB，单次请求最多 600 张，包含历史对话中的图片，且需满足 Token 限制。 |

### 已知限制

- 图片会在内部缩放至约 2048 x 2048 像素以内；超过 5500 x 5500 像素的输入会被拒绝。如需识别精细内容或小字，建议先裁剪相关区域。
- 执行代码、编辑文件或操作应用，需要具备相应外部工具和权限的运行环境。
- 多轮工具工作流需要保留模型的推理历史，以维持工具调用之间的连续性。
