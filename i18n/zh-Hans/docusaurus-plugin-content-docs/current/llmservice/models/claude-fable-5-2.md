# Claude Fable 5.2

## 概述

Claude Fable 5.2 是 Anthropic 于 2026 年 11 月 9 日发布的 Claude 模型，面向复杂推理、软件工程和长时间运行的 Agent 工作流。该模型与 Claude Mythos 5.2 采用相同的底层模型，并增加网络安全和生物学安全机制，以面向通用场景开放。

## 核心特性

- **复杂技术任务：** 面向需要持续规划与迭代的高难度编码、数学推理、科学分析和工程任务。
- **自适应推理：** 始终启用自适应思考，根据任务调整推理，并提供五档 effort，以平衡深度、延迟和 Token 用量。
- **大上下文工作空间：** 支持 1M Token 上下文窗口和最高 128K Tokens 输出，可处理大型代码仓库、参考资料和详细交付内容。
- **Agent 工具与结构化结果：** 支持自动工具调用、严格工具 Schema、JSON 输出，以及通过外部工具完成计算机操作工作流。
- **改进的视觉与沟通能力：** 可解读图像、图表和示意图。Anthropic 表示，其解释和总结相比早期 Fable 模型更加清晰。
- **更快的生成速度：** Anthropic 表示，输出生成速度相比 Fable 5.1 最高提升 30%。详见[发布公告](https://www.anthropic.com/claude-fable-and-mythos-5-2)。

## 适用场景

- **代码仓库级工程任务：** 适用于代码迁移、复杂调试、性能优化，以及跨多个文件和工具的实现任务。
- **深入研究：** 适用于结合证据收集、定量分析和迭代验证的多步骤研究。
- **专业交付内容：** 通过适当工具，将复杂资料整理为报告、电子表格、演示文稿及其他成品。
- **视觉与工程分析：** 结合文字需求，解读技术示意图、图表、截图和设计参考。

## 能力与限制

| 能力 | 说明 |
| :--- | :--- |
| **推理** | 始终启用自适应思考；effort 支持 `low`、`medium`、`high`、`xhigh` 和 `max`，Claude API 默认使用 `high`。 |
| **多模态** | 文本和图像输入，文本输出。 |
| **上下文窗口** | 1,000,000 Tokens。 |
| **最大输出** | 128,000 Tokens。 |
| **工具调用** | 支持自动函数调用和计算机操作；使用客户管理的加密密钥时，不支持严格工具 Schema 和结构化 JSON 输出。 |
| **Prompt 缓存** | 支持 5 分钟和 1 小时缓存时长；可缓存 Prompt 的最小长度为 512 Tokens。 |
| **知识截止时间** | 2026 年 6 月。 |

### 已知限制

- 不支持强制工具选择；集成时应使用自动工具选择或禁用工具调用。
- 保留思考内容依赖此前上下文保持不变。修改早期指令、工具或消息，可能导致思考块失效并引发 API 错误。只有 Fable 5.2 和 Mythos 5.2 可以读取 Fable 5.2 的思考块。
- 安全机制会阻止大多数网络安全相关任务，并限制生物学请求。部分专业 AI 开发任务也受到限制，或可能回退到早期模型。
- 长任务可能在完成前停止，尤其是在较低 effort 档位下；工作流应检查所需结果是否完整。
