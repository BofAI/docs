# Kimi K2.8 Preview

## 概述

Kimi K2.8 Preview 是 Moonshot AI 于 2026 年 9 月 11 日发布的 K2 系列预览模型，面向编程与 Agent 工作流。其 API 模型 ID 为 `kimi-k2.8-preview`，支持 1,048,576 Token 上下文窗口、图像与视频理解以及可调节推理。Moonshot AI 表示，该模型的综合性能接近 Kimi K3，同时相比 K2.7 Code 具备更高效的思考能力。

## 核心特性

* **编程与 Agent 能力**：面向代码补全和日常开发任务；根据模型提供方信息，其编程与 Agent 能力相比 K2.7 Code 有所提升。
* **可调节推理**：支持 `low`、`high` 和 `max` 三种推理强度，默认为 `max`，也可以关闭思考模式。
* **1M 上下文窗口**：支持 1,048,576 Token 上下文，可容纳大型代码库、辅助文档和较长的对话历史。
* **视觉输入**：除文本外还支持图像和视频输入，可用于结合截图、界面参考或录屏内容的开发任务。

## 适用场景

* **日常软件开发**：代码补全、功能实现、调试和测试生成，并可根据任务复杂度选择推理强度。
* **代码库分析与重构**：在较大规模的代码及文档上下文中审查依赖关系，并协调跨文件修改。
* **视觉辅助开发**：理解 UI 截图或屏幕录制内容，用于指导实现或排查问题。
