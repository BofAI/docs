# Gemini 4 Hydrogen

## 概述

Gemini 4 Hydrogen 是 Google DeepMind 于 [2026 年 11 月 12 日](https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-gemini-4-hydrogen/)发布的 Gemini 4 系列模型。该模型基于 Gemini 4 Carbon 调整而来，面向高效的日常编程、Agent 执行和多模态知识工作，支持可调节推理和统一的 1M Token 上下文窗口。

## 核心特性

- **迭代编程：** 支持代码仓库探索、问题解决、调试和针对性的代码修改。
- **Agent 执行：** 处理多步骤工具工作流，也可与其他模型配合，作为执行或验证子任务的 Agent。
- **多模态分析：** 结合文本、文档、图片、图表、音频和录制视频进行研究与信息整合。
- **可调节推理：** 提供四档思考级别，以平衡推理深度、响应时间和 Token 用量。
- **扩展生成：** Long Decode 可在剩余上下文预算内支持较长的报告、代码和推理内容。

## 适用场景

- **软件维护：** 排查问题、回答代码仓库相关问题、实现修复，并通过测试检查修改。
- **文档研究：** 将报告、表格、图表和录制素材整理为摘要或结构化结论。
- **Web 原型开发：** 构建交互式应用，并通过反复实现与检查优化界面。
- **执行与验证 Agent：** 在协同 Agent 工作流中执行明确的子任务、收集证据并检查结果。

## 能力与限制

| 能力 | 说明 |
| :--- | :--- |
| **推理能力** | 支持 `low`、`medium`、`high`（默认）和 `xhigh` 思考级别。 |
| **多模态能力** | 支持文本、图片、音频、视频和 PDF 输入，输出文本。 |
| **文档格式** | Google Cloud API 还支持 Word、PowerPoint、Excel 和 OpenDocument 文件。 |
| **上下文窗口** | 输入、思考、函数调用和最终输出共同使用 [1,048,576 Token](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/gemini/4-hydrogen) 的统一预算。 |
| **生成上限** | 默认同步单段的思考、函数调用和最终输出合计最多 65,536 Token；Long Decode 可通过续接或后台处理使用统一上下文中的剩余预算。 |
| **工具使用** | 支持函数调用、代码执行、URL 上下文、grounding，以及通过兼容集成进行计算机操作。 |
| **结构化输出** | 支持受 Schema 约束的响应，用于信息提取和结构化交付。 |
| **视频理解** | 支持 Agent 视频处理，需手动启用；默认使用静态处理模式。 |
| **提示词缓存** | Google API 对至少 4,096 Token 的共享提示词前缀使用隐式缓存，不支持显式缓存。 |
| **知识截止时间** | 2026 年 3 月，部分领域知识可能更早。 |

### 已知限制

- **共享生成预算：** 思考和函数调用会消耗输出 Token。更高的思考级别可能增加 Token 用量和延迟，在固定上限下为最终回答留下的空间更少。
- **输出长度：** 模型不能可靠保证精确的字数或 Token 长度。
- **生成控制：** 自定义 `temperature`、`top_p` 和 `top_k` 值会被忽略，不支持 `minimal` 思考级别和显式思考预算。
- **可靠性：** 仍可能出现幻觉、偶发响应缓慢和超时；事实性结论和生成的代码均需验证。
