# GPT-6.2 Sol

## 概述

GPT-6.2 Sol 是 OpenAI 面向日常编程、专业工作和智能体工作流的 GPT-6.2 推理模型，于 [2026 年 11 月 17 日发布](https://developers.openai.com/api/docs/changelog)。它结合文本与图像理解、工具使用和长上下文能力，为复杂工作提供比 Astra 成本更低的选择。

## 核心特性

- **日常软件开发**：支持在现有代码库中修复缺陷、添加功能及完成其他开发工作。
- **迭代任务执行**：处理需要持续测试和修订的多步骤任务。
- **工具型智能体**：通过 Responses API 使用搜索、代码执行、计算机操作及连接的工具。
- **可调节推理**：帮助应用平衡推理深度、响应时间和 Token 消耗；OpenAI 建议新接入时从 medium 强度开始。
- **长工作上下文**：结合 1.05M Token 上下文窗口和提示词缓存，复用指令与参考资料。
- **智能体任务委派**：支持 Responses API Multi-agent 测试版，将独立子任务交给子智能体处理。

## 适用场景

- **代码库维护**：根据明确的验收标准修复缺陷、添加范围明确的功能及修改代码。
- **运营助手**：完成结合信息检索、应用交互和工具调用的重复性工作流。
- **文档起草**：将笔记和源材料整理成待审核初稿，并根据反馈修改。
- **文档与图像分析**：结合截图或其他图像审核长篇参考材料，输出结构化结论。

## 能力与限制

| 能力 | 说明 |
| :--- | :--- |
| **推理** | 支持 `low`、`medium`、`high`、`xhigh` 和 `max`；不支持 `none` 和 `minimal`。 |
| **多模态** | 支持文本和图像输入、文本输出；不支持原生音频和视频。 |
| **上下文窗口** | [1,050,000 Token](https://developers.openai.com/api/docs/models/gpt-6.2-sol)，由输入和生成的 Token 共同占用。 |
| **最大输入** | 922,000 Token。 |
| **最大输出** | 128,000 Token，包含推理和可见输出。 |
| **工具使用** | 通过 Responses API 中的工具支持函数调用、网页与文件搜索、代码执行、计算机操作、MCP 和图像生成。 |
| **结构化输出** | 支持 Structured Outputs 和流式输出。 |
| **提示词缓存** | 通过 Responses API 支持隐式和显式缓存，最低有效期为 30 分钟或 12 小时。 |
| **知识截止时间** | 2026 年 6 月 1 日。 |

### 已知限制

- 工具调用需要使用 Responses API；Chat Completions 支持不含工具的请求。
- 不支持采样和对数概率控制；不支持微调。
- 推理会消耗输出预算，并可能增加延迟；输出预算不足时，响应可能在生成可见回答前就已处于未完成状态。
- 修改较早的对话内容或切换到较小的模型，可能丢弃此前的推理内容，降低上下文连续性并增加重复工作。
