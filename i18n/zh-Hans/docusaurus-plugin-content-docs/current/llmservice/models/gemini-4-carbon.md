# Gemini 4 Carbon

## 概述

Gemini 4 Carbon 是 Google DeepMind 推出的 Gemini 4 系列推理模型，于 [2026 年 11 月 10 日](https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-4-carbon-now-available/)正式面向公众开放。该模型基于 Gemini 4 Argon 构建，面向高难度软件工程、科学研究和多模态知识工作，强调更深入的推理和扩展验证。

## 核心特性

- **持续工程工作流：** 通过反复调查、实现与验证，处理复杂调试、架构变更和迁移任务。
- **科学推理：** 支持数学证明、实验数据分析、假设探索和仿真开发。
- **多模态分析：** 结合文档文字、图表、图片、音频和视频，对不同来源的资料进行推理。
- **可配置思考：** 提供三档推理级别，以平衡深度、响应时间和 Token 消耗。
- **扩展生成：** 支持 Long Decode，适用于需要超过默认 64K Token 生成预算的问题。

## 适用场景

- **复杂代码仓库维护：** 跨子系统排查问题、规划迁移，并结合现有测试检查变更。
- **文档分析：** 将复杂报告、表格、图表和技术图纸整理为结构化结论和报告草稿。
- **研究与仿真：** 探索数学或科学问题、分析实验结果，并构建计算模型。
- **全栈与视觉开发：** 构建应用、优化界面，并通过工具辅助验证实现交互式 3D 场景。

## 能力与限制

| 能力 | 说明 |
| :--- | :--- |
| **推理能力** | 支持 `low`、`medium`（默认）和 `high` 思考级别。 |
| **多模态能力** | 支持文本、图片、视频、音频和 PDF 输入，输出文本。 |
| **上下文窗口** | 输入、思考和输出共同使用 1,048,576 Token 的统一预算。 |
| **生成上限** | 默认思考与输出合计最多 65,536 Tokens；Long Decode 可使用统一上下文中的剩余预算。 |
| **工具使用** | 支持函数调用、代码执行、File Search、URL 上下文、Search 与 Maps grounding，以及计算机操作。 |
| **结构化输出** | 支持受 Schema 约束的结构化响应。 |
| **视频理解** | 支持 Agent 视频理解，视频处理模式默认使用 `static`。 |
| **提示词缓存** | Google API 对至少 4,096 Token 的提示词默认启用隐式缓存；不支持显式缓存。 |
| **知识截止时间** | 2026 年 3 月，部分领域知识可能更早。 |

### 已知限制

- **推理预算与延迟：** Carbon 每轮通常比 Argon 消耗更多思考 Token。生成预算过小时，可能没有足够空间输出答案；复杂提示词可能需要数分钟或出现超时。
- **Long Decode 要求：** 生成超过 65,536 Token 的内容，需要提高输出上限，并采用后台执行或客户端续接。模型不能可靠保证精确的输出长度。
- **不支持的参数与输出：** `temperature`、`top_p` 和 `top_k` 会被忽略。不支持原生图像生成、原生音频生成和 Live API。
- **网络安全版本：** 专门的网络安全能力及 Google 公布的相关评测结果，适用于通过 Fairwind Program 验证的防御者访问版本。
- **可靠性：** 仍可能出现幻觉；事实性陈述、科学结论和生成的代码均需验证。
