# GPT-6.2 Astra

## 概述

GPT-6.2 Astra 是 OpenAI 面向高难度软件工程和专业项目的 GPT-6.2 推理模型，于 [2026 年 11 月 17 日发布](https://developers.openai.com/api/docs/changelog)。它结合文本与图像理解、可调节推理和工具使用能力，用于规划和完成复杂工作。

## 核心特性

- **复杂项目处理**：规划并执行项目，根据新增信息调整处理方式。
- **软件工程**：结合代码执行和编辑工具构建、修订软件，并辅助实现和验证。
- **视觉计算机操作**：解读截图，并配合计算机操作工具跨应用完成任务。
- **长工作上下文**：1.05M Token 上下文窗口可容纳大量源材料、代码及对话历史。
- **智能体任务委派**：支持 Responses API Multi-agent 测试版，将独立子任务交给子智能体处理。
- **清晰写作**：默认倾向于简洁直接的表达，可根据受众调整语气和细节。

## 适用场景

- **复杂软件项目**：需要跨组件反复测试的实现、调试和代码审核工作。
- **研究与技术决策**：比较证据、检验假设并权衡不同方案的开放式分析。
- **专业交付物**：将详细需求和参考材料整理成报告、文档或应用，并持续迭代修订。
- **计算机工作流**：通过界面、文件和连接的工具协调一系列操作。

## 能力与限制

| 能力 | 说明 |
| :--- | :--- |
| **推理** | 支持 `low`、`medium`、`high`、`xhigh` 和 `max`；不支持 `none` 和 `minimal`。 |
| **多模态** | 支持文本和图像输入、文本输出；不支持原生音频和视频。 |
| **上下文窗口** | [1,050,000 Token](https://developers.openai.com/api/docs/models/gpt-6.2-astra)，由输入和生成的 Token 共同占用。 |
| **最大输入** | 922,000 Token。 |
| **最大输出** | 128,000 Token，包含推理和可见输出。 |
| **工具使用** | 通过 Responses API 中的工具支持函数调用、网页与文件搜索、代码执行、计算机操作、MCP 和图像生成。 |
| **结构化输出** | 支持 Structured Outputs 和流式输出。 |
| **提示词缓存** | 通过 Responses API 支持隐式和显式缓存，最低有效期为 30 分钟或 12 小时。 |
| **知识截止时间** | 2026 年 5 月 18 日。 |

### 已知限制

- 工具调用需要使用 Responses API；Chat Completions 支持不含工具的请求。
- 不支持采样和对数概率控制；不支持微调。
- 推理会消耗输出预算，并可能增加延迟；输出预算不足时，响应可能在生成可见回答前就已处于未完成状态。
- 修改较早的对话内容或切换到较小的模型，可能丢弃此前的推理内容，降低上下文连续性并增加重复工作。
