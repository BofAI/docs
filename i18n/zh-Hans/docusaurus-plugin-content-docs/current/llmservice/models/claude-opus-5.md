# Claude Opus 5

## 概述

Claude Opus 5 是 Anthropic 面向复杂智能体编程、长时间运行工作流和专业知识工作的模型。在 B.AI 中使用模型 ID：`claude-opus-5`。

## 核心特性

* **自适应思考：** 支持 `effort` 控制（`low`、`medium`、`high`、`xhigh` 和 `max`），用于平衡推理深度、响应延迟和 token 消耗。
* **长上下文：** 最多支持 1,000,000 个 token 上下文和 128,000 个 token 输出，适合长文档、代码仓库和多步骤工作流。
* **多模态理解：** 支持文本和图片输入、文本输出，可用于文档、图表、示意图和界面分析。
* **工具调用工作流：** 支持函数调用和结构化输出；其他工具能力取决于 B.AI API 配置。
* **提示词缓存：** 符合条件的请求支持 5 分钟和 1 小时缓存写入价格档位。

## 适用场景

* **智能体软件工程：** 仓库级实现、调试、重构、代码审查和测试修复验证工作流。
* **长时间运行自动化：** 结合规划、工具调用、中间验证和失败恢复的多步骤任务。
* **专业知识工作：** 研究综合、文档分析、结构化提取和专业交付物生成。
* **长上下文分析：** 大型代码库、长文档、PDF、图表、示意图和其他视觉参考资料。

## 能力与限制

| 能力维度 | 说明 |
| :--- | :--- |
| **推理能力** | 支持带有可配置 `effort` 的自适应思考。较高的 effort 可能增加推理深度、响应延迟和 token 消耗。 |
| **创意写作** | 支持通用文本生成、长文写作和专业文档起草。 |

| **最大输出** | 最多 128,000 个 token。 |
| **工具调用** | 支持函数调用和结构化输出；其他工具能力取决于 B.AI API 配置。 |
| **多语言能力** | 适用于多语言自然语言和开发者工作流。 |

### 已知限制

* 超长上下文、大输出和较高推理强度可能增加响应延迟和 Credits 消耗。
* 将新工作流部署到生产环境前，请先在测试环境确认工具可用性和请求参数。
* 缓存行为和缓存资格取决于请求格式及平台配置。
