# JEV-1.13.0

## 概述

JEV-1.13.0 是 TypeSafe AI 面向软件工作流中快速结构化决策的 System One 模型。它根据类型化问题评估传入的上下文，并返回选项、评分和概率，供应用程序执行后续操作。使用 `jev-1.13.0` 可固定稳定版本；`jev-latest` 当前解析到同一模型。

## 核心特性

* **类型化决策输出**：支持分类选择（`Choice`）、基于量表的评估（`Score`）和是/否概率估计（`Noul`），可选答案由应用程序定义。
* **不确定性信号**：Choice 和 Score 返回概率分布及派生的置信度，便于处理模糊情况。
* **并行评估**：多个独立问题可以共享同一个状态并同时运行，减少顺序 API 调用。
* **面向决策的训练**：使用校准决策强化学习（RLCD），针对聚焦型语义判断进行训练。
* **可组合工作流逻辑**：应用程序可通过明确规则和权重组合多个判断，并由代码控制最终操作。

## 适用场景

* **请求路由与客服分流**：同时判断意图、紧急程度和复杂度，再将请求路由到软件处理器、专用模型或人工审核。
* **RAG 段落过滤**：在将检索材料交给生成模型前，评估相关性、支持证据和矛盾内容。
* **内容筛查**：根据明确的规则标准和严重程度评估消息。
* **工具选择**：从已知函数和枚举参数中选择工具，并由应用代码校验和执行所选操作。

## 能力与限制

| 能力维度 | 说明 |
| :--- | :--- |
| **API 接口** | 使用 `POST https://api.b.ai/v1/decisions`，请求包含 `state`、`model` 和 `questions`。详情参见 [Decisions API 参考](../api/decisions-api.md)。 |
| **模型 ID** | `jev-1.13.0` 为稳定版本；`jev-latest` 当前解析到该版本。 |
| **推理能力** | 针对聚焦型语义判断优化；复杂决策应拆分为范围明确的问题，并在代码中组合。 |
| **输入模态** | 仅支持文本，可使用字符串、JSON 对象或数组提供。 |
| **上下文限制** | 单次请求的状态与全部问题合计最多 64K Token；状态与最长单个问题合计最多 32K Token。 |
| **输出类型** | 输出类型化决策，而非生成式文本或代码。Choice 最多支持 255 个选项；Score 支持 2-10 个有序等级；Noul 返回 0 到 1 之间的值。 |
| **置信度** | Choice 和 Score 包含根据概率分布计算的置信度；Noul 不单独返回置信度字段。 |
| **工具调用** | 可通过针对已定义候选项的类型化问题选择工具；工具执行和非枚举参数提取需要应用逻辑完成。 |
| **多语言能力** | 主要训练语言为英文；包括中日韩文本在内的其他语言需要针对具体负载进行验证。 |

### 已知限制

* 符合 Schema 不代表判断一定正确。应使用代表性数据验证置信度阈值；需要保持行为一致时，应固定使用带版本号的模型 ID。
* 算术、计数、日期比较和多跳推理可靠性有限；精确计算应由代码完成，并使用范围明确的判断标准。
* JEV 不生成自由形式的解释、摘要或代码；当候选值可以枚举时，更适合用于提取任务。
