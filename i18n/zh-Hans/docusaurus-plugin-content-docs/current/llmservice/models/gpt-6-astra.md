# GPT-6 Astra

## 概述

GPT-6 Astra 是 OpenAI 首款 6 系列模型，于 2026 年 9 月 3 日发布，面向软件开发、浏览器操作、研究和专业应用中的复杂端到端工作。模型 ID 为 `gpt-6-astra`。它结合可配置推理、Computer Use 能力和 1.05M token 上下文窗口，适合长时间运行、工具密集型工作流。

## 核心特性

* **Agent 计算机操作**：结合视觉理解、Computer Use、浏览和工具执行能力，可完成多步骤工作流。
* **软件工程**：支持 Hosted Shell、Code Interpreter、Apply Patch 及其他 Responses API 工具，可处理复杂工程任务。
* **长上下文推理**：提供 1.05M token 上下文窗口，最大输出为 128K tokens。
* **异步 Agent 工作流**：支持异步工具调用和回合中引导，应用可在响应进行期间补充指令或工具结果。
* **可配置推理**：支持 `low`、`medium`、`high`、`xhigh` 和 `max` 推理强度。

## 适用场景

* **长周期软件工程**：适合需要持续上下文和多次工具调用的代码库级实现、调试、迁移和验证任务。
* **浏览器与桌面自动化**：适合在人工监督下操作网站或专业软件、识别视觉状态并完成多步骤任务。
* **研究与科学分析**：结合长上下文推理、浏览、代码执行和文档分析，处理证据密集型研究和技术工作流。
* **业务内容制作**：按照既有模板和用户反馈，创建及修改结构化文档、表格、演示文稿和分析内容。

## 能力与限制

| 能力维度 | 说明 |
| :--- | :--- |
| **推理能力** | 支持 `low`、`medium`、`high`、`xhigh` 和 `max` 推理强度；不支持 `none`。 |
| **计算机操作** | 支持视觉理解和 Computer Use 工作流；实际表现取决于应用框架、工具、防护措施和任务环境。 |
| **多模态能力** | 支持文本和图像输入、文本输出。 |
| **上下文窗口** | 1,050,000 tokens。 |
| **最大输出** | 128,000 tokens。 |
| **工具调用** | 通过 Responses API 支持函数调用、Structured Outputs、网页搜索、文件搜索、图像生成、Code Interpreter、Hosted Shell、Apply Patch、Computer Use、MCP、Skills 和 Tool Search。 |
| **知识截止时间** | 2026 年 4 月 30 日。 |

### 已知限制

* GPT-6 Astra 不支持 `none` 推理强度。
* 输入超过 272K tokens 的请求会对整次请求采用更高费率。
* 生产环境的安全防护和监控可能拒绝、暂停或终止部分敏感请求，包括部分合法的防御性安全工作。
