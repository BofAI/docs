# Qwen3.7-Flash

## 概述

[Qwen3.7-Flash](https://www.qwencloud.com/models/qwen3.7-flash) 是阿里巴巴 Qwen 团队于 2026 年 7 月 25 日发布的高性价比原生视觉语言模型。它结合了百万 Token 上下文、视觉理解、多模态编程和工具驱动的任务执行能力。

**模型 ID：** `qwen3.7-flash`。

## 核心特性

- **原生多模态理解：** 支持分析文本、图像和视频，识别物体、空间关系和真实世界场景。
- **长上下文：** 在 1,000,000 Token 上下文窗口内处理大型文档集合、代码库和长对话。
- **可选思考模式：** 可对复杂任务启用推理，也可在简单请求中关闭思考。
- **视觉编程：** 支持结合文字说明与截图等视觉参考完成编程任务。
- **结构化工作流：** 支持函数调用、前缀续写、上下文缓存和结构化 JSON 输出。

## 适用场景

- **文档与视觉分析：** 从文档、截图、图表和图像中提取信息。
- **编程辅助：** 生成和调试代码，或根据视觉参考实现界面。
- **长上下文问答：** 基于大量参考资料或对话历史回答问题。
- **工具驱动助手：** 将模型推理与外部工具结合，用于搜索、分析和多步骤任务。

## 能力与限制

| 能力维度 | 说明 |
| :--- | :--- |
| **推理能力** | 支持混合思考模式，默认开启，可按请求选择是否启用。 |
| **输入与输出** | 支持文本、图像和视频输入；输出为文本。 |
| **上下文窗口** | 1,000,000 Token。 |
| **最大输入** | 非思考模式为 991,808 Token；思考模式为 983,616 Token。 |
| **最大输出** | 两种模式均为 131,072 Token。 |
| **工具调用** | 支持通过函数调用连接外部工具和系统。 |
| **结构化输出** | 支持 JSON Object 和 [JSON Schema](https://docs.qwencloud.com/developer-guides/text-generation/structured-output) 输出模式。 |
| **上下文缓存** | 支持共享输入前缀的显式缓存和自动隐式缓存。 |

### 已知限制

- 视频理解不包含视频中的音轨，不支持音频输入。
- 思考会增加生成时间，并产生按输出价格计费的 Token 用量。

### 分档与缓存计费

- 按请求的总输入长度选择价格档位，该档位适用于本次请求的全部输入和输出 Token。思考 Token 按输出价格计费。
- 隐式缓存创建的 Token 按普通输入价格计费，不额外收取缓存写入费用；命中后按隐式缓存读取价格计费。
- 显式缓存新写入的 Token 按显式缓存写入价格计费，替代这些 Token 的普通输入费用，不重复叠加收取。
- 显式缓存和隐式缓存是两种互斥模式，适用价格分别见上表。
- [显式缓存](https://www.alibabacloud.com/help/en/model-studio/context-cache)有效期为 5 分钟，命中后刷新有效期；自动隐式缓存不保证每次命中。
