# Claude Opus 5.5

## 概述

Claude Opus 5.5 是 Anthropic 于 2026 年 9 月 22 日发布的模型，面向长期软件工程、自主 Agent 和专业知识工作。在 B.AI 上使用的模型 ID 为 `claude-opus-5.5`。该模型结合 1M Token 上下文窗口与始终开启的自适应思考能力。

## 核心特性

* **Agent 编程**：面向仓库级工程、迭代测试和长周期工具工作流。
* **可调节推理**：支持 `low`、`medium`、`high`、`xhigh` 和 `max`，默认为 `medium`；自适应思考无法关闭。
* **大型工作上下文**：支持 1M Token 上下文和最高 128K Token 输出，不收取长上下文附加费。
* **工具与结构化结果**：支持自动工具选择、严格 Schema、结构化输出、计算机和浏览器操作，以及对话中途的系统消息。
* **视觉与专业写作**：支持图表、示意图、截图、文档、代码解释和商业交付物。

## 适用场景

* **仓库级工程**：需要持续上下文、迭代测试和工具调用的迁移、调试及代码审查。
* **业务 Agent**：需要保留上下文并协调子任务的多步骤应用工作流。
* **文档分析**：审阅报告和电子表格，并根据文本与视觉证据生成摘要。
* **视觉应用工作流**：通过计算机和浏览器工具理解截图或操作界面。

## 能力与限制

| 能力维度 | 说明 |
| :--- | :--- |
| **推理能力** | 始终开启自适应思考，支持 `low`、`medium`（默认）、`high`、`xhigh` 和 `max`。 |
| **多模态能力** | 支持文本和图像输入，输出文本；支持 PDF 分析和视觉内容理解。 |
| **上下文窗口** | 1M Token。 |
| **最大输出** | 128K Token。 |
| **工具调用** | 支持客户端和服务端工具、自动函数调用、严格 Schema 和结构化输出；不支持强制指定工具。 |
| **提示词缓存** | 最低可缓存提示词长度为 512 Token，支持 5 分钟和 1 小时缓存。 |
| **知识截止日期** | 2026 年 6 月。 |

### 已知限制

* 关闭思考、手动设置 `budget_tokens`，或将 `tool_choice` 强制设为 `any` 或指定工具会返回 400 错误。
* 保留的思考内容与模型及先前上下文绑定；不兼容的编辑或模型切换可能使重放内容失效或被丢弃。
* 安全机制拒绝可能返回 HTTP 200 和 `stop_reason: "refusal"`，因此仅凭 HTTP 成功不能判断任务已经完成。
