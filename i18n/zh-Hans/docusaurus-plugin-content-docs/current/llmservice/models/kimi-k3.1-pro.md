# Kimi K3.1 Pro

## 概述

[Kimi K3.1 Pro](https://www.kimi.com/en/blog/kimi-k3-1-pro) 是 Moonshot AI 的首款 K3.1 系列旗舰模型，基于 Kimi K3 进一步后训练打造，属于 3 万亿参数级模型。它结合原生视觉理解和 1M Token 上下文窗口，增强了编程、3D 创作、金融研究及多步骤 Agent 能力。

## 模型版本

| 模型 | API 模型 ID | 说明 |
| :--- | :--- | :--- |
| **Kimi K3.1 Pro** | `kimi-k3.1-pro` | 标准版本，输入、输出和缓存写入价格更低。 |
| **Kimi K3.1 Pro Highspeed** | `kimi-k3.1-pro-highspeed` | 智能水平和上下文窗口与标准版相同；据 Moonshot AI 介绍，速度约为标准版的 2 至 3 倍，适合交互式编程及对延迟敏感的 Agent 工作流。 |

## 核心特性

- **软件工程**：支持代码库修复、调试和完整项目构建，可在具备工具的环境中开发交互式网站和游戏。
- **3D 与空间推理**：根据草图、参考图和文字需求编写 Blender 或 CAD 脚本，构建参数化模型和场景。
- **金融研究与建模**：通过连接检索和执行工具，支持跨文档分析、数值推理及电子表格建模。
- **可调节推理**：提供 low、high 和 max 推理强度，用于平衡推理深度、延迟与 Token 用量。
- **长上下文视觉理解**：在 1,048,576 Token 上下文窗口内处理文本、图像和视频，适合大型代码库及参考资料。

## 适用场景

- **代码库开发**：结合文件、终端和测试工具排查问题、实现功能，并迭代大型项目。
- **交互式网站与游戏原型**：根据文字或视觉参考构建前端界面、Three.js 场景和游戏体验。
- **参数化 3D 设计**：为机械零件、建筑模型、家具和可配置产品生成并优化脚本。
- **金融分析**：借助适当工具比较报告、追溯依据，并制作研究成果或关联电子表格模型。

## 能力与限制

| 能力 | 说明 |
| :--- | :--- |
| **推理** | 始终启用，支持 low、high 和 max 强度，默认为 max。 |
| **输入与输出** | 支持文本、图像和视频输入；输出文本，包括代码和结构化 JSON。 |
| **上下文窗口** | 1,048,576 Token，由输入和生成的输出共同占用。 |
| **最大输出** | [默认 131,072 Token](https://platform.kimi.ai/docs/api/chat)，可配置至 1,048,576 Token，但受剩余上下文容量限制。 |
| **工具使用** | 支持函数调用和动态工具加载，用于多步骤工作流。 |
| **结构化输出** | 支持 JSON 模式和 JSON Schema 输出，包括嵌套对象与数组。 |
| **流式输出** | 支持逐步输出推理内容和最终回答。 |

### 已知限制

- 采样参数固定：temperature 为 1.0，top-p 为 0.95；每次请求仅支持生成一个结果。
- 多轮对话和工具调用工作流需保留完整的 assistant 消息，包括推理历史。
- 生成 3D 资产、运行代码或编辑电子表格，需要适当的外部工具和执行环境。
