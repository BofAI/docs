# Hy4 Flash

## 概述

[Hy4 Flash](https://intl.cloud.tencent.com/document/product/1300/80695) 是腾讯 Hy4 系列的轻量模型，面向日常办公和高频、大规模任务，结合文本与图像理解、百万 Token 上下文、深度思考和工具调用能力。

## 核心特性

- **日常办公：** 面向撰写、总结和信息处理等高频办公任务。
- **长上下文分析：** 可在百万 Token 上下文中处理大量文档、参考资料和对话历史。
- **视觉理解：** 识别图像中的文字、理解图表，并结合文字指令分析截图。
- **灵活推理：** 默认开启深度思考，简单请求可选择关闭。
- **工具协作：** 支持函数调用、思考保留和结构化输出，适用于结合推理与外部工具的工作流。

## 适用场景

- **办公助手：** 撰写往来文书、总结报告并整理日常业务信息。
- **文档与图表分析：** 从扫描件提取信息、解读图表，并结合文字资料比较图像内容。
- **编程辅助：** 解释代码、排查问题，结合项目上下文辅助代码生成和重构。
- **工作流自动化：** 借助外部工具检索信息、处理结果，并通过多步骤流程生成结构化响应。

## 能力与限制

| 能力 | 说明 |
| :--- | :--- |
| **输入与输出** | 支持文本和图像输入，输出文本，包括代码和结构化响应。 |
| **推理** | 默认开启深度思考，可关闭；支持在工具交互过程中保留思考历史。 |
| **上下文窗口** | 1M Token。 |
| **最大输入** | 960,000 Token。 |
| **最大输出** | 64,000 Token。 |
| **工具调用** | 通过函数调用连接外部工具，完成多步骤工作流。 |
| **结构化输出** | 支持结构化响应，用于信息提取和后续处理。 |
| **图像输入** | 支持 PNG、JPEG、WEBP 和静态 GIF；单张不超过 10 MB，每次请求最多 600 张（包含历史对话中的图像），同时受 Token 上限约束。 |

### 已知限制

- 图像会在内部缩放至约 2048 × 2048 像素，超过 5500 × 5500 像素的输入会被拒绝；关注小字或精细内容时，建议先裁剪相关区域。
- 执行代码、编辑文件或操作应用，需要运行环境具备相应外部工具和权限。
- 使用思考保留的工具工作流，应在请求之间保留模型未经修改的思考历史，以获得更好的效果。
