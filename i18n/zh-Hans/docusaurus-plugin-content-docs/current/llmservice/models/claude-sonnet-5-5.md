# Claude Sonnet 5.5

## 概述

Claude Sonnet 5.5 是 Anthropic 于 2026 年 9 月 28 日发布的模型，面向边界明确的软件工程、日常 Agent 工作流和专业文档创作。在 B.AI 上使用的模型 ID 为 `claude-sonnet-5.5`。该模型结合 1M Token 上下文窗口与自适应思考能力，是 Claude Opus 5.5 更快、成本更低的补充选择。

## 核心特性

* **Agent 编程**：Anthropic 发布的评测表显示，该模型在 Terminal-Bench 4.0 和 CursorBench 4.0 上的成绩分别为 70.6% 和 55.5%；这些是模型提供方公布的评测结果，不代表生产环境保证。
* **可调节推理**：五档推理强度可平衡推理深度、延迟和 Token 使用量。默认启用自适应思考；`between_tools` 可取消工具调用前的预先思考，适合需要更快首次响应的工作负载。
* **大型工作上下文**：支持 1M Token 上下文且不收取长上下文附加费，可处理长文档、代码库和长对话。
* **工具与结构化结果**：支持客户端和服务端工具、结构化输出、严格工具 Schema，以及通过受支持工具执行计算机和浏览器操作。
* **视觉与文档工作**：支持理解图像和 PDF，并可配合相应工具生成报告、演示文稿、电子表格和用户界面。

## 适用场景

* **边界明确的软件工程**：适合需要快速迭代和重复工具调用的缺陷修复、代码审查与功能实现。
* **业务交付物**：结合文档和执行工具，将源材料整理为报告、演示文稿和电子表格分析。
* **文档与视觉分析**：利用大型上下文窗口和图像理解能力审阅长报告、图表和截图。
* **交互式 Agent**：适用于通过推理强度控制来平衡响应速度、推理能力和成本的多步骤支持及内部工作流。

## 能力与限制

| 能力维度 | 说明 |
| :--- | :--- |
| **推理能力** | 默认启用自适应思考，支持 `low`、`medium`、`high`（Claude API 默认）、`xhigh` 和 `max`；`between_tools` 仅支持 `low`、`medium` 或 `high`。 |
| **多模态能力** | 支持文本和图像输入，输出文本；支持 PDF 分析。 |
| **上下文窗口** | 1M Token。 |
| **最大输出** | 标准请求最高 128K Token，由思考内容和可见输出共享。 |
| **工具调用** | Claude API 支持自动工具选择、结构化输出和严格 Schema；支持对话中途系统消息，逐消息推理强度、工具变更和按需压缩属于 Beta 功能。 |
| **提示词缓存** | 最低可缓存提示词长度为 512 Token，支持 5 分钟和 1 小时缓存。 |
| **知识截止日期** | 2026 年 6 月。 |

### 已知限制

* 使用 `thinking: {"type": "disabled"}`、手动思考预算、非默认采样参数、Assistant 预填充，或将 `tool_choice` 强制设为 `any` 或指定工具会返回 400 错误。
* 思考块与原始账户或关联账户绑定，并受模型兼容性限制；应保持思考块不变，并采用仅追加的对话方式。
* 工具调用之间较长的进度说明会出现在思考块中，默认在自适应思考模式下隐藏。应按区块类型解析响应，不能假设第一个区块就是可见文本。
* 较低推理强度可能在长任务完成前停止或跳过验证，较高推理强度可能加入未要求的内容；复杂、开放式任务仍更适合 Opus 5.5。
* 安全机制拒绝可能返回 HTTP 200 和 `stop_reason: "refusal"`。可选的服务端回退功能仍处于 Beta 阶段，成功响应可能来自其他模型。
