# GPT-6.1 Terra

## 概述

GPT-6.1 Terra 是 OpenAI 于 [2026 年 10 月 26 日发布](https://developers.openai.com/api/docs/changelog)的 GPT-6 系列模型，面向高效视觉推理、精确计算机操作及清晰自然的文本写作。它结合文本与图像理解和可调节推理能力，适合日常专业工作流。在 B.AI 上使用的模型 ID 为 `gpt-6.1-terra`。

## 核心特性

- **视觉推理**：解读商品照片、技术图纸和应用截图，辅助比较与分析。
- **计算机操作**：配合计算机操作工具浏览界面，并跨应用完成任务。
- **自然写作**：根据提供的材料起草和修改简洁文本，兼顾受众与表达风格。
- **可调节推理**：提供包括 `none` 在内的六档推理强度，用于平衡推理深度、响应时间和 Token 消耗。
- **长工作上下文**：1.05M Token 上下文窗口可容纳大量参考资料及对话历史。

## 适用场景

- **视觉审核与匹配**：将商品图片与目录条目匹配，或对照需求比较技术图纸。
- **应用工作流**：通过连接的工具完成目标明确的屏幕操作，例如录入信息或更新记录。
- **商务写作**：将提供的笔记和参考材料整理成简洁的初稿、摘要和修订内容。
- **范围明确的代码修复**：在需求和验证步骤清晰时，对现有代码进行针对性修改。

## 能力与限制

| 能力 | 说明 |
| :--- | :--- |
| **推理** | 支持 `none`、`low`、`medium`（默认）、`high`、`xhigh` 和 `max`。 |
| **多模态** | 支持文本和图像输入、文本输出；不支持原生音频、视频输入或输出。 |
| **上下文窗口** | [1,050,000 Token](https://developers.openai.com/api/docs/models/gpt-6.1-terra)，由输入和生成的 Token 共同占用。 |
| **最大输出** | 128,000 Token，包含推理和可见输出。 |
| **工具使用** | 通过 Responses API 中的工具支持函数调用、网页与文件搜索、计算机操作、代码执行、MCP 和图像生成。 |
| **结构化输出** | 支持 Structured Outputs 和流式输出。 |
| **提示词缓存** | 通过 Responses API 支持隐式和显式缓存，最低有效期为 30 分钟或 12 小时。 |
| **知识截止时间** | 2026 年 6 月 1 日。 |

### 已知限制

- 工具调用需要使用 Responses API；Chat Completions 支持不含工具的请求。
- 启用推理时，不支持 `temperature`、`top_p` 和对数概率控制；不支持微调。
- 推理可能增加延迟，并在生成完整可见回答前消耗输出预算。
- 对于复杂项目和高难度分析，GPT-6.1 Sol 或 GPT-6 Astra 可能更合适。
