# Claude Haiku 5.5

## 概述

Claude Haiku 5.5 是 Anthropic 于 2026 年 10 月 7 日发布的 Claude 5.5 系列轻量模型，面向高频调用和对延迟敏感的工作负载。在 B.AI 上使用的模型 ID 为 `claude-haiku-5.5`。该模型结合自适应思考与 1M Token 上下文窗口，适用于分类、信息提取、摘要和边界明确的 Agent 任务。

## 核心特性

* **快速处理日常任务**：适用于请求路由、数据库查询和对话摘要等重复性工作负载。
* **可调节推理**：首款支持五档推理强度的 Haiku 模型，可平衡推理深度、响应时间与 Token 使用量。
* **大型工作上下文**：支持最高 1M Token 上下文，可处理长文档和较长的对话历史。
* **视觉理解**：支持文本和图像输入，可用于截图、图表及其他视觉内容的分析。
* **工具与 Agent 工作流**：支持工具调用和结构化输出，可配合计算机、浏览器工具处理界面操作和边界明确的子 Agent 任务。

## 适用场景

* **分类与路由**：对客服工单和内容进行分类，并将请求分配至对应工作流。
* **文档提取与摘要**：从源材料中提取指定信息，压缩报告和对话历史。
* **实时客户支持**：处理需要快速响应、范围明确的高频问题。
* **辅助编程**：在大型编程工作流中承担范围明确的检索、摘要和辅助任务。
* **界面自动化**：在合适的工具执行环境中完成简短的浏览器或计算机任务。

## 能力与限制

| 能力维度 | 说明 |
| :--- | :--- |
| **推理能力** | 默认启用自适应思考，支持 `low`、`medium`（默认）、`high`、`xhigh` 和 `max` 五档推理强度。 |
| **思考控制** | 在 `low`、`medium` 或 `high` 强度下可以关闭思考，更高强度要求启用思考。 |
| **多模态能力** | 支持文本和图像输入，输出文本，支持多语言。 |
| **上下文窗口** | 1M Token。 |
| **最大输出** | 标准请求最高 128K Token，由思考内容和可见输出共享。 |
| **工具调用** | 支持工具调用和结构化输出；计算机、浏览器操作需要受支持的工具及执行环境。 |
| **提示词缓存** | 支持 5 分钟和 1 小时缓存。 |
| **知识截止日期** | 2026 年 6 月。 |

### 已知限制

* **复杂 Agent 任务**：复杂、长周期的编程任务仍更适合 Sonnet 5.5 和 Opus 5.5；Haiku 5.5 更适合范围明确的任务。
* **完成可靠性**：较低推理强度可能跳过搜索、提前停止或不验证代码改动。在 `xhigh` 强度下，部分多轮响应可能结束但没有可见文本，应检查任务完成情况和响应内容。
* **结构化输出与工具**：关闭思考时，模型在生成 JSON 的过程中可能跳过必要的工具调用。结合结构化输出与自定义工具的工作流建议启用自适应思考。
* **迁移兼容性**：不支持手动思考预算、Assistant 预填充和非默认采样控制。新分词器对相同文本产生的 Token 数量可能比 Haiku 4.5 多约 30%，具体取决于内容。
